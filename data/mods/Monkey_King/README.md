# 猴王传承 0.4.1

作者：g1ytx。

## 安装

只需将安装包内的 `Monkey_King` 文件夹放入游戏外部 `mods/` 或 `data/mods/`，
确保 `mods/Monkey_King/mod.lua` 直接存在，不要再套一层版本号文件夹。
创建世界时启用「猴王传承」，创建角色时搜索职业「花果山行者」。
职业受场景可选职业列表限制；基础六项变异也可在特质页单独选择。

从旧版更新时，删除旧 Mod 文件夹后换入新版，并移除旧的 `Monkey_King_Pilgrim`
扩展文件夹，防止重复定义职业。已启用旧扩展的世界须先备份，并从启用列表移除
`Monkey_King_Pilgrim`，保留 `Monkey_King`。角色的六项变异和职业 ID 均未改变。

## 花果山行者

8点娱乐向强力职业，自带全部六项传承，无需在特质页重复选择。
长棍、长袍、长裤、草鞋、背包、塑料瓶、绷带各一项；未另行配置饮水。
近战3、钝击3、闪避2、生存2、游泳2。不会给旧角色自动转职或补发装备。
职业 ID：`MONKEY_KING_PILGRIM`。

## 0.4.1 更新

金刚猿躯新增5%百分比减伤，使用原生 `ARMOR_ALL` 附魔：可抵抗伤害在护甲结算前
乘以0.95，再计算衣甲与变异防护。100点伤害在这一阶段变为95点，不是固定减5点。
纯粹等 `no_resist` 伤害、直接扣血和状态效果不受此项减免影响；其他 Mod 新增的
可抵抗伤害类型也适用。其他同类附魔依引擎规则合并，最终扣血仍受护甲和取整影响。
已有金刚猿躯的角色重新加载更新后的 Mod 即可获得该效果，不需要再选一次变异。

## 数值说明

独立选择六项变异共23点，受角色创建模式限制。它们不会随机获得或被净化剂移除。
生命上限按120%实现；力量另有影响，各来源按引擎规则叠加并取整。
清醒恢复沿用原生机制，受角色状态和游戏设置影响，不是每回合回满。
防护覆盖标准人类十二部位；元素防护不涵盖全部法术、控制、环境温度或纯粹伤害。
齐天神力通常额外增加10点氧气上限（原生公式为30 + 2 × 当前力量）；合成肺例外。
筋斗身法不提供飞行，水行猿息不提供水下呼吸。

## 实现与验证

本版恢复为单文件夹、全 Lua：六项变异、附魔、职业和装备组都通过
Lua Platform v1 的 `require("ccb")` 注册，没有 JSON/EOC 内容。

**需要包含职业同批变异引用校验修复的 CCB 引擎。**
报告中的 `2026-09-07-f9865475-dirty` 旧程序不包含这项修复，单独更新 Mod
不会修好旧引擎。该修复位于 `src/lua_platform_content_character.cpp`；
在引擎更新前，应继续使用0.3.2的静态职业兼容版本。
从0.3.2更新需先移除旧目录中的 `profession.json`，再安装本版，避免重复职业。

源码附有原生回归测试，涵盖同批引用、外观分支、错误引用和回滚。
编译和运行验证结果以本次交付说明为准，不能把 Lua 模拟注册当成原生实测。
